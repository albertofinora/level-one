# Level One – Club del Videogioco

App per votare le proposte del club, dare l'hype, valutare i giochi e consultare le statistiche dei gusti del gruppo.

- Configurazione e gestione: vedi **GUIDA_ADMIN.md**
- Guida per i membri: **GUIDA_MEMBRI.md** (visibile anche dentro l'app)

Prova in locale: `pip install -r requirements.txt` e poi `streamlit run app.py`.
